Pull request footer colors now distinguish open, auto-merge, and merged states. The watching eye stays neutral so you can identify pull request state at a glance.

## 🔧 Changes

### Distinct pull request footer colors

Pull request footer icons now use the theme’s `success` color for open PRs, `warning` for auto-merge, `accent` for merged PRs, and `dim` for drafts. The watching eye uses the normal `text` color instead of the accent color, keeping it distinct from merged PRs. GitHub state errors still dim all icons.
